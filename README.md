# Cybersecurity-Hub

A Python-based web vulnerability scanner built with Flask, requests, BeautifulSoup, and socket programming to scan and analyze target websites for security flaws.

## Features
- Lightweight Flask web interface.
- Automated vulnerability and reconnaissance checks.
- Clean and intuitive reporting dashboard.

## Tech Stack
- **Backend:** Python, Flask
- **Libraries:** Requests, BeautifulSoup4, Socket
- **Frontend:** HTML5, CSS3
